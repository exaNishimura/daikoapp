# 売掛・請求書・日次売上 運用マニュアル

このドキュメントはオーナー（管理者）向けの運用ガイドです。日々の入力フロー・月次の請求業務・トラブル時の復旧手順をまとめています。

---

## 画面一覧

| URL | 画面 | 用途 |
| --- | --- | --- |
| `/admin/receivables` | 売掛一覧 | 日々の売掛入力・編集・CSV 出力 |
| `/admin/sales` | 日次売上 | 日次の車両売上・スタッフ稼働・固定経費入力 |
| `/admin/invoices` | 請求書 | 月次の請求書発行・入金管理・未入金確認 |
| `/admin/companies` | 取引先マスタ | 取引先（顧客）の追加・編集・並び替え |
| `/admin/company-profile` | 自社情報 | 請求書ヘッダに刷り込む自社情報の編集 |
| `/admin/receivables/import` | Excel インポート | 過去データの移行・運用復旧（緊急時のみ） |

---

## 日々の流れ

### 1. 売掛の入力（運転代行 1 件ごと）

`/admin/receivables` を開く。

1. 上部の「対象月」が今月になっているか確認。
2. 右側の「+ 売掛を追加」ボタンをクリック。
3. 取引先 → 日付 → 出発 → 到着 → 金額 → 備考 を入力。
4. 「保存して続けて入力」をクリックすると、同じ取引先で次の行を続けて入力できます。

> **入力済みの売掛**は表内で直接編集できます。請求書発行済み（鍵マーク）の行は編集・削除がロックされます。先に請求書を取消してください。

### 2. 日次売上の入力（毎日 1 行）

`/admin/sales` を開く。

- 1〜31 日のすべての行が表示されます。土日は色付き。
- 各セルに値を入力すると **500ms 静止で自動保存**されます。
- 入力項目: 距離(1)/(2)、燃料(1)/(2)、売上(1)/(2)/(3)、経費内容、経費金額、現金。
- 派生表示: 総売上 / 燃料計 / 推定収益 がリアルタイム計算されます。
- スタッフ別売上タブ: セルクリックで「その日の全スタッフ分」を一括入力するダイアログが開きます。
- 固定経費タブ: 共済掛金 / 損害保険 / 駐車場 / 携帯 / 税理士 を入力すると月次サマリに反映されます。

## 月次の流れ

### 月末: 請求書発行

`/admin/invoices` を開く。

1. 上部で対象月（例: 2026 年 5 月）を選択。
2. タブ「新規発行」を選択。
3. 取引先ごとに件数・合計が一覧表示されます。
4. **件数 18 件以下** の取引先はそのまま「通常発行」。
5. **件数 19 件以上** の取引先は警告バナーが出て、戦略を選択:
   - **合算**: 17 件目までを通常通り表示、18 件目に「その他 合計¥XXX」として残りを集約（1 枚で発行）
   - **分割**: 18 件ずつ複数枚に分けて発行（「(1/2)」「(2/2)」のような表記が請求書名に付く）
   - **スキップ**: その取引先は発行しない
6. 不要な取引先はチェックを外す。
7. 「N 社を発行」ボタンをクリック。
8. 結果ダイアログで個別ダウンロード / 一括 zip ダウンロード可能。

> **同月の二重発行は不可**: 同じ取引先で既に発行済みの月は、そのまま再発行できません。先に「取消」してください。

### 入金記録

タブ「発行済一覧」または「未入金一覧」で:

- **入金チェックボックス** を on にすると `paid_at = NOW()` が記録されます。
- off に戻すと未入金扱いに戻ります。
- 入金済みになると取消ボタンが無効化されます（誤操作防止）。

### 未入金確認

タブ「未入金一覧」では:

- 全期間の未入金請求書を `billing_month` 昇順で表示。
- サマリエリア: 総未収金 / 件数 / 平均滞留日数 / **60 日超アラート**。
- 60 日を超えている請求書は赤背景 + 赤い Chip で目立つ表示。
- 企業別未収金カードで、滞留日数の長い取引先を一目で確認できます。

## 取引先マスタの管理

`/admin/companies` を開く。

- **追加**: 「+ 取引先を追加」ボタン
  - 名前（必須）
  - 請求書表示名（請求書に刷り込む形式名、空欄なら名前を使用）
  - 別名（aliases）: Excel インポート時のマッチング用に複数登録可
  - 並び順: 売掛一覧などでの表示順
- **編集**: 行のアイコンから
- **無効化**: トグルで `is_active=false` に。過去の売掛は残り、新規入力時の選択肢から除外されます。
- **並び替え**: ドラッグで自由に変更可能。

---

## 自社情報

`/admin/company-profile` を開く。

- 屋号 / 住所 / 電話 / インボイス番号（適格請求書発行事業者番号）/ 振込先銀行情報 を編集。
- ここに保存された値は、**請求書発行時にスナップショットされて invoices テーブルに永続化**されます。
- 過去の請求書には発行時点の自社情報が残ります（編集しても過去には影響しない）。

## 緊急時: Excel インポート（運用復旧用）

通常は使いません。日々の運用は `/admin/receivables` から直接入力してください。

過去データの一括移行や、Web 入力ができなかった期間の復旧などで使う場合のみ:

`/admin/receivables/import` を開く（売掛画面の右上の「Excel インポート」リンクから）。

### 手順

1. `YYYYMM稼働管理表new.xlsx` 形式のファイルをドロップゾーンに入れる。
2. ファイル名から自動的に年月が判定されます（不一致ならエラー）。
3. **取引先マッピング**: 売掛シートの企業名と既存マスタの照合結果が表示されます。
   - 自動マッチ済み（name / alias / 表示名のいずれかと完全一致）はそのまま。
   - 未マッチは Select で「既存統合（候補から選択）」または「スキップ」を選択。
   - **新規企業として追加** したい場合は、先に `/admin/companies` で取引先を追加してから戻ってください。
4. **同月既存データの扱い**:
   - **マージ**: 重複を除いて追加挿入（既存はそのまま）。デフォルト推奨。
   - **上書き**: 同月の既存データを全削除してから新規挿入。**ただし請求書発行済みの売掛があると不可**。
   - **スキップ**: 既存があるので取り込まない。
5. プレビュータブで 集計 / 売掛 / スタッフ / 固定経費 の取り込み内容を確認。
6. 「この内容で保存」をクリック。
7. 結果 Alert で挿入件数 / 削除件数 / 重複スキップ / マッピング未解決スキップ が表示されます。

### トラブルシュート

- **「ファイル名から年月を抽出できません」**: ファイル名が `YYYYMM稼働管理表` 形式である必要があります。`202605稼働管理表new.xlsx` など。
- **「請求書発行済みデータが含まれます」**: 上書きしようとした月に発行済みの請求書があります。先に該当請求書を取消してから再実行。
- **未マッピングが残っている**: スキップにするか、`/admin/companies` で取引先を追加してから戻ってください。

## データ構造（参考）

### テーブル一覧

| テーブル | 役割 |
| --- | --- |
| `companies` | 取引先マスタ |
| `company_profile` | 自社情報（シングルトン） |
| `accounts_receivable` | 売掛（運転代行 1 件 1 行） |
| `invoices` | 請求書ヘッダ |
| `daily_sales` | 日次の車両売上・経費集計 |
| `daily_staff_sales` | 日次のスタッフ別売上・稼働 |
| `staff_rates` | スタッフ単価マスタ（時間制 or 歩合制） |
| `monthly_fixed_expenses` | 月額固定経費 |

### 一意性キー

- `accounts_receivable`: `(billing_month, company_id, work_date, departure, destination, amount)` で重複検出
- `invoices`: `(company_id, billing_month)` で同月二重発行を防止
- `daily_sales`: `work_date`
- `daily_staff_sales`: `(work_date, staff_name)`
- `monthly_fixed_expenses`: `(billing_month, label)`

### 派生計算

- `daily_sales.total_sales = vehicle1_sales + vehicle2_sales + vehicle3_sales` （GENERATED 列）
- `daily_sales.profit = total_sales - expense_amount - vehicle1_fuel_yen - vehicle2_fuel_yen` （GENERATED 列）
- スタッフ人件費（クライアント計算）:
  - 時間制: `hours × hourly_rate`
  - 歩合制: `sales × commission_rate`
- 月次推定粗利（クライアント計算）: `総売上 - 経費 - 燃料 - 人件費 - 固定経費`

## 認証と権限

- すべての `/admin/*` ページは Supabase Auth 経由でログインが必要（Magic Link）。
- 未認証ユーザは `/login` にリダイレクト。
- RLS（Row Level Security）は `authenticated` ロールのみ参照・更新可。
- 請求書発行・取消・入金記録は SECURITY INVOKER RPC で実行（個別 INSERT/UPDATE は使わない）。

## 開発者向けメモ

- 純関数とユーティリティは `src/lib/billing/` 配下に集約（テスト容易）。
- React Query で `staleTime=60s` のキャッシュ + onSuccess invalidate でデータ整合性確保。
- Excel 生成は ExcelJS、Excel パースは SheetJS (xlsx) を使い分け。
- 統合テスト（実 Excel ファイル依存）: `npm run test:integration`
- 通常テスト + lint + build: `npm test` / `npm run lint` / `npm run build`
