## 抽出ルール

- 出典: [日本郵便 郵便番号データ（UTF-8・1レコード1行）](https://www.post.japanpost.jp/service/search/zipcode/download/utf-zip.html)
- 対象市区町村: 鈴鹿市 / 亀山市 / 四日市市 / 津市
- 「以下に掲載がない場合」など町名ではないレコードは除外
- 括弧書きの注記（ビルを除く、次の丁目、など）は除去
- 先頭の「大字」は町名として扱うため除去
- 同一町名は1件にまとめ、代表郵便番号は番号順の先頭

## 所要時間マップでの使い方

アプリの「配車 → 所要時間マップ」（`/travel-times`）が、この町名一覧をデータソースにしている。

- 市を切り替えて、出発地点（空欄なら現在地、入力すれば待機場所）からの車での所要を計算する
- 所要は Google Distance Matrix（運転、可能なら渋滞考慮）
- マーカー色: 緑 15分以内 / 青 30分以内 / 橙 45分以内 / 赤 45分超
- 町名の再抽出: `node scripts/extract-area-towns.mjs`（`KEN_ALL_CSV` で utf_ken_all.csv のパスを指定）
