# Source Prompt

> 本機能の起点となった依頼内容と、その後の合意事項を記録する。requirements / design / tasks の根拠資料として参照する。

## 機能名

receivable-billing（売掛管理・月次請求書発行システム）

## 依頼の本旨

運転代行チョロ急の売掛管理と請求書発行を、Excel ベースの運用から `daikoapp`（既存の React + Vite + Supabase アプリ）に**完全移行**したい。

**ポイント（オーナーとの合意事項）**

- Excel 運用から **脱却** するのが目的
- Excel インポートは **過去データの初期移行と、運用が破綻したときの保険** に位置づける（毎月の運用ルートではない）
- 日々の入力（売掛発生・売上計上・経費入力）は **web アプリ上で行う**
- 月末に **請求書 Excel ファイルを企業ごとに自動生成** する。これは取引先に渡す体裁が確立しているため Excel 出力は維持
- 個人情報は含まない、機密情報は売上数値のみ

## 入力 Excel：`YYYYMM稼働管理表new.xlsx`

### シート①「集計」（range A2:AS62、ヘッダ 2 行）

```

C=走行距離1号車   D=走行距離2号車
E=燃料代1号車     F=燃料代2号車
G/H = チョロモン 売上/稼働時間   ※歩合制（掛率0.3）
I/J = 井上     売上/稼働時間   ※時間制 ¥1,150/h
K/L = 伊藤     売上/稼働時間   ※時間制 ¥1,300/h
M/N = 西村     売上/稼働時間   ※時間制 ¥1,300/h
O/P = たかし   売上/稼働時間   ※時間制 ¥1,100/h
Q/R = しゅうや 売上/稼働時間   ※時間制 ¥1,100/h
S/T = 山崎     売上/稼働時間   ※時間制 ¥1,100/h
U/V = 臨時1   売上/稼働時間   ※時間制 ¥1,100/h
W/X = 臨時2   売上/稼働時間   ※時間制 ¥1,000/h
Y   = 売上計算チェック ("OK")
Z   = 1号車売上
AA  = 2号車売上
AB  = 3号車売上

AK  = 現金
AL  = 収益/日
AM-AQ = 距離効率/距離スコア/時間効率/時間スコア/総合
```

シート 35 行目以降にサマリ（「合計」「立替払い」「燃費計算」「曜日別平均売上」「月額固定経費」）が記載される。**取り込みは一次データ（A〜AL の日次行）のみ。サマリは DB 側で再計算する。**

### シート②「売掛」（range B3:I90）

```
B3 = タイトル "YYYY年M月売掛記録"
F3 = "合計¥XXX,XXX"（全社合計）
B4 = ヘッダ "請求先" / C4="日" / D4="出発地" / E4="到着地" / F4="金額" / G4="備考"
B5以降 = データ行
```

- 取引先ごとにブロック化、**ブロック内は同じ請求先名が縦に並ぶ**
- ブロックの **空行で区切り**
- 一部ブロックは取引先名だけ並んで明細ゼロ（その月に依頼が無かった企業）
- 「日」列は `"5日"` 形式の文字列（年は無く、ファイル名から年月補完）

### 値のパース仕様

| 表記 | 型 | パース |
|---|---|---|
| `"¥41,000"` / `"¥27,000-"` | integer (yen) | 数字以外を除去、空は null |
| `"175km"` | numeric (km) | `km` を除去、空は null |
| `"9.50h"` | numeric (hours) | `h` を除去 |
| `"5日"` | day-of-month | `日` を除去、年月はファイル名から |
| `"2026年5月31日"` | date | YMD パース |
| `"OK"` | flag | 表示用、保存不要 |

ファイル名 `202605稼働管理表new.xlsx` から `year=2026, month=5` を抽出（正規表現 `^(\d{4})(\d{2})稼働管理表`）。

## 既存スタックとの統合

- **フロント**: React 18 + Vite + react-router-dom 7 + MUI v7（emotion）。**Tailwind / shadcn / Radix は撤去済み。**
- **状態管理**: TanStack Query。クエリキーは `src/lib/queryClient.js` に追加。
- **DB**: Supabase（PostgreSQL）。マイグレーションは `supabase/migrations/YYYYMMDDHHMMSS_*.sql` 形式。
- **認証**: 既存の Supabase Auth。RLS は `authenticated` ロールに限定する既存方針に追従。
- **import パス**: `@/components/...` `@/hooks/...` `@/lib/...` `@/utils/...`
- **テスト**: Vitest + RTL。パース・生成系は単体テスト必須。

## 使用ライブラリ

- `xlsx` (SheetJS) — 読み込み（インストール済）
- `exceljs` — テンプレ書き込み（インストール済）
