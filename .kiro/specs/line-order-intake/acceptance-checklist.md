# LINE 受注 受け入れチェックリスト（手動）

## 顧客 LIFF（要件 1, 7）

- [ ] 公式 LINE / `/liff/order` からフォームが開く
- [ ] Places Autocomplete で住所候補が出る（または手入力可）
- [ ] 必須: 日時（または今すぐ）・お迎え・お帰り・車両・電話
- [ ] 複数台追加できる
- [ ] 申込成功で仮受付メッセージ（不可時は理由、営業外今すぐは日時促し）
- [ ] 500円引き表示
- [ ] 自分の予約をキャンセルできる
- [ ] 時間変更 UI が無い（再申込のみの案内がある）

## 管理画面（要件 5, 11）

- [ ] ナビ「配車 → LINE仮受付」でキューを開ける
- [ ] 未承認・要手配・ホールド残が表示される
- [ ] 詳細に日時・住所・車両・電話・LINE・割引が出る
- [ ] 正しい PIN で台ごと承認 → 顧客に完了通知
- [ ] 不正 PIN でエラー、承認されない
- [ ] 時間変更・削除ができ顧客通知される

## 設定（要件 2, 5, 9）

- [ ] `/admin/line-settings` で割引額・台数・extra・PIN を更新できる
