# Source Prompt

公式LINE（既存1チャネル）＋LIFFで代行運転を24時間受け付ける。
顧客識別はLINE userId。住所はPlaces Autocomplete。電話番号は連絡用。

営業日基準。電話受付は19:00開始。最短お迎えは指定日の稼働台数＋バッファで算出
（平日想定1台・金土2台・将来3台）。事前予約は稼働に対し仮想余裕枠+1〜+2（設定可変）を見込める。
余裕枠利用時は管理画面・グループに要手配と明示。実車両マスタは自動増減しない。

営業時間外の「今すぐ」は受けず日時指定を促す。
Google Mapsで所要時間取得し、配車表・予約台帳と突合して可否判定。
電話優先。電話が確保／否決した時間帯はLINE予約不可。

可なら仮受付を管理画面表示＋グループLINE通知、顧客へ仮受付完了。
ホールド: 19:00以降の営業時間内は15分。それ以外は次の19:00まで。
期限切れ時は顧客へ「予約できなかった／指定時間が埋まっている可能性」を通知して枠解放。

承認は管理画面のみ。固定共有6桁PIN。台ごと承認。誰でもPIN入力で可。
承認後、公式LINEからその台の予約完了メッセージ。

当日（当該営業日）は配車ボード系、それ以外は予約台帳系へ。
顧客はキャンセル可（時間変更はキャンセル後再予約のみ）。管理者は時間変更・削除可。
リマインド: 顧客はお迎え60分前1通。管理者は当日営業開始前に確定分一覧1通。

LINE経由割引はMVPで一律500円引き。割引額は設定変更可。円/%・条件・複数台適用などは拡張可能な設計にする。
Messaging APIは既存トークンで顧客userId pushとLINE_GROUP_ID pushを併用。
