# Product Overview

代行運転事業の業務管理Webアプリケーション。電話で受けた依頼の配車から、シフト管理、従業員管理、月次の売上集計・請求書発行まで、運営に必要な業務を1つのアプリで完結させる。

## Core Capabilities

- **配車管理**: 電話受注した依頼を配車係が登録し、車両タイムラインへドラッグ&ドロップで割り当て・確定。Google Maps API による所要時間自動計算と、同一車両の時間重複（競合）検出を組み合わせて配車ミスを防止。
- **シフト管理**: 月次カレンダー表示と編集ページで従業員のシフトを登録・複製・一括コピー。
- **従業員管理**: ドライバー等の従業員マスタを管理し、配車・シフト・売上配賦の基礎データとして利用。
- **請求業務 (Receivable / Billing)**: 売掛先（会社）ごとの請求対象を集計し、ExcelJS で請求書 Excel を生成・保存。日次/月次の売上、スタッフ別売上、スタッフ単価、固定費も管理。
- **売上シート取り込み**: 既存運用の Excel シート（日報・売掛シート）を読み込み、データに変換する。
- **認証**: Supabase Auth のマジックリンク方式によるログインで、管理系画面（シフト編集・従業員管理）を保護。

## Target Use Cases

- 鈴鹿市近辺の代行運転事業者における、電話受注 → 配車確定までの日常オペレーション。
- 複数車両の稼働状況を1画面で視覚的に管理。
- 月次の請求書発行と売上集計（売掛先・スタッフ別・固定費）。
- 既存 Excel 運用からの段階的なデジタル化（売上シートの取り込みなど）。

## Value Proposition

配車・シフト・売上/請求という事業オペレーションを1つのアプリに集約し、視覚的なタイムライン管理と自動化されたルート計算・競合検出により、配車効率と事務作業の精度を同時に向上させる。Excel との相互運用（取り込み / 出力）により、既存業務フローを壊さずに移行できる点も特徴。
